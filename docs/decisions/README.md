# Decisions

One short file per decision that others will live with: `NNNN-short-title.md`, numbered in order.
Write it on your branch so it merges with the code. About 10 lines:

```
# NNNN Short title
Date: YYYY-MM-DD   Author: <who>
## Context
One or two lines: what forced the decision.
## Decision
What we do now.
## Rejected
The options we did not take, and why in a few words.
## Consequences
What this makes easier or harder; what to revisit and when.
```

A decision is not edited later. To change one, add a new file that says it supersedes the old one.
